# 02-design — UX & Design System

Designer-owned (active only when the lifecycle profile has a design phase).

- `ux-strategy.md`, `ia.md`, `journeys/`, `screens/`, `design-system.md`, `accessibility.md`, `handoff.md`, `audits/`.
- The canonical component/token system is root `DESIGN.md`, owned per OD-02 by the primary design tool; this directory holds strategy, justification, and audit evidence.
- Every interactive state and responsive breakpoint documented; accessibility target recorded (default WCAG 2.2 AA for shipped UI).
- Feasibility sign-off from Developer and testability notes from QA required before the design gate.
